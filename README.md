# Révision Coran

Appli web (PWA) pour réviser les sourates qu'on connaît, sous forme de cartes à glisser.

- 8 modes : aya suivante, aya précédente, compléter, mot manquant, quelle sourate, remettre en ordre, réciter (reconnaissance vocale ou auto-évaluation), écoute
- Pièges : propositions tirées des ayat qui se ressemblent (mutashabihat)
- Sélection des sourates et d'une plage d'ayat par sourate
- Répétition espacée, suivi par sourate, série de jours
- Fonctionne hors ligne

Texte arabe uthmani (Hafs, Complexe du Roi Fahd, via QuranEnc) · traduction Muhammad Hamidullah (celle de quran.com/fr) · audio everyayah.com
